# Asymmetric Semantic Fragility: Analyzing Directional Bias in Transformer-Based NLP Models

* This project explores Asymmetric Semantic Fragility (ASF) in transformer-based Natural Language Processing models by analyzing their sensitivity to minor semantic perturbations. 
* Controlled experiments are conducted on models such as DistilBERT and RoBERTa to evaluate changes in classification performance under subtle input variations. 
* The results demonstrate that small contextual changes can significantly impact model predictions and confidence levels. 
* The study highlights critical robustness limitations and provides insights for developing more reliable and resilient NLP systems.
